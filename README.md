# Калькулятор ВОРОНИНА

Работающая версия: **https://voronina-revenue-calculator.fizzysheep2.chatgpt.site**. Опубликована 12.11.2026 через Sites.

Калькулятор показывает условные сценарии роста выручки через конверсию, повторные покупки и средний чек с ограничением мощности. После расчёта объясняет числа и предлагает варианты первого действия. Это не прогноз прибыли и не гарантия роста.

## Исходники и просмотр

`site/dist` содержит исходники публичной версии; `site/.openai/hosting.json` — идентификатор существующего сайта. При обновлении нужно использовать этот сайт, а не создавать новый. Для локального просмотра можно запустить из корня репозитория:

```sh
python -m http.server 8000 --directory site/dist --bind 127.0.0.1
```

Откройте http://127.0.0.1:8000. Без сервера можно открыть [автономный HTML](preview/revenue-diagnostic.html), собранный из той же версии.

Формулы независимы от интерфейса и находятся в `site/dist/core.js`. Сценарии соответствуют достижению 25%, 50% и 100% разницы до введённых целей. Поток обращений и мощность сохраняются; чек общий для первых и повторных покупок. Прибыль и изменение спроса на цену не моделируются.

Данные считаются в браузере. В публичной версии нет формы отправки контактов, аналитики и серверной передачи показателей. Для разбора пользователь самостоятельно переходит в Telegram.

Проверки: 25 автоматических тестов исходного проекта пройдены; финансовое ядро скопировано без изменений. JavaScript и состав статических ресурсов проверены. Развёртывание подтверждено платформой; браузерная проверка нового интерфейса в текущей среде недоступна. Контрольный пример: 300 000 ₽ → 354 375 / 412 500 / 540 000 ₽.
