Пакет страницы калькулятора для Apache-хостинга Timeweb

Состояние: подготовка к переносу; не опубликован, DNS не переключён.
Источник: действующая версия Sites 17, коммит f844f27412fb3ba586698db5a23ab53ddf6efb1f.

Содержимое public_html — только публичные файлы страницы, статическая конфигурация адреса приёма и правила Apache. Ключей базы, Telegram, расшифрования, пользовательских анкет и квитанций здесь нет.
Файлы страницы скопированы без изменения расчётов, оформления и фотографий. Их контрольные суммы приведены в package-manifest.json.

На Timeweb не переносится база и не создаётся отдельный отправитель. Браузер отправляет анкету прямо в существующий российский обработчик Яндекс Облака. Локальный маршрут /api/config сообщает только его публичный адрес. cloudDeliveryEnabled=false отключает дополнительный вызов отправителя на сервере страницы, которого в статическом пакете нет. Проверенное облачное расписание Sites продолжает читать сохранённые заявки и доставлять их в Telegram каждый час. Мгновенная отправка на новом хостинге не заявляется; обычная задержка повторной доставки — до следующего часового запуска при исправных внешних сервисах.
Публикация этого пакета не меняет текущие ключи, функции, расписание или сайт на техническом адресе Sites.

Порядок завершения после разрешения и активации постоянного хостинга
1. Убедиться, что у аккаунта Timeweb активна оплаченная услуга размещения, а не заканчивающийся тестовый период.
2. Сохранить существующую папку сайта, если она непустая. Разместить содержимое public_html в отдельном корне сайта, сохраняя файл .htaccess.
3. Привязать margarititavoronina.ru к подготовленному корню. Сохранить исходные DNS: A 162.159.143.30 и A 172.66.3.26. MX, NS и TXT не менять.
4. Подготовить бесплатный SSL Let's Encrypt штатными средствами Timeweb. По документации Timeweb для выпуска A-запись уже должна указывать на сервер хостинга. Поэтому сначала выполнить все доступные проверки файлов и серверных правил, затем в согласованное окно переключить только A-записи и сразу запустить выпуск сертификата. Во время выпуска возможна временная недоступность HTTPS; предупреждение браузера не обходить.
5. Использовать актуальный адрес сервера Timeweb: на момент подготовки панель показывала 92.53.96.225, перед переключением сверить снова. После выдачи SSL проверить HTTPS, главную страницу и /api/config. Правила пакета переводят HTTP основного домена на HTTPS, оставляя доступным только технический путь проверки сертификата.
6. Проверить HTTPS, все ресурсы, расчёт и отправку вымышленной анкеты именно с домена. Убедиться, что последующее облачное расписание подтвердило доставку.
7. Если новый сервер или SSL неработоспособны, вернуть сохранённые A-записи. Рабочую копию Sites и облачное расписание не удалять.

Ограничения проверки
Локальная проверка пакета не заменяет реальное развёртывание Apache, выдачу сертификата и сквозной тест домена. 25 ноября панель Timeweb подтвердила: тестовый период закончился, обслуживание приостановлено до оплаты, баланс 0 рублей. Последняя подтверждённая стоимость тарифа Optimo — 729 рублей в месяц. Платная услуга и списание не активированы. Снятие 403 до выполнения реального переключения не заявляется.
