Облачное расписание
Создана связанная с Sites задача Automation_d9346a0135748191bd49732aeb09b6b3 «Доставлять анкеты калькулятора в Telegram». Она включена, интервал — один час, часовой пояс Asia/Yekaterinburg. Первый плановый запуск указан на 24.11.2026 21:00 (+05:00).
Создание расписания ещё не подтверждает успешное выполнение. Нужен результат реального запуска с доступом к инструменту deliver_calculator_queue.
Начальный текст задачи содержит проверку фиксированной вымышленной анкеты перед очередью. После подтверждения доступа его следует заменить обычной последовательностью calculator_delivery_health → deliver_calculator_queue без обязательного повторного теста: иначе удаление тестовой записи по сроку хранения остановит задачу.
Инструмент Codex automation_update поддерживает изменение локальных cron/heartbeat, поэтому изменение этой облачной задачи через него не выполнено. Вход в веб-управление расписанием через разрешённый Google-аккаунт остановился на сетевой ошибке accounts.google.ru. Новый Google-доступ, чтение почты или Drive не использовались.
