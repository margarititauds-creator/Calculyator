24 ноября 2026 года, 23:24 по Екатеринбургу (UTC+05:00).

Подтверждено
Контрольный запуск сохранённой облачной задачи «Доставлять анкеты калькулятора в Telegram» доставил одну вымышленную анкету: 1 отправлена, 0 ошибок, 0 требуют внимания. Запуск выполнен кнопкой «Запустить сейчас» в веб-управлении расписанием; сама обработка выполнялась в облаке.
До запуска анкета была сохранена в российской базе со статусом pending. Отправитель на ПК и публичный маршрут немедленной отправки для этой анкеты не вызывались. После облачного запуска проверка квитанции вернула HTTP 200, sent; отдельное чтение той же записи подтвердило delivered и Telegram messageId=11. Из базы читалась только эта известная вымышленная запись, без расшифрования других анкет.
Контрольная запись: a63eb3e0-95d1-4c1c-ba2a-17033c742199. Квитанция доступа не публикуется.

Что исправлено
Старый отправитель Яндекс Облака при неудаче переносил dueAt, из-за чего независимый почасовой отправитель мог пропустить сохранённую заявку. Теперь облачная задача выбирает до пяти записей очереди, включая отложенные в пределах одного часа, и условно возвращает свободную запись в готовое состояние. Активная аренда другого обработчика, истёкший срок хранения и ограничение попыток сохраняются. Доставленные и удержанные записи не восстанавливаются автоматически.
Проверки: 66 из 66 прошли командой node --test test/*.test.mjs. Добавлены случаи отложенной заявки, активной аренды, истечения срока, ограничения попыток и одновременного захвата записи. Это эквивалент npm test из package.json; команда npm не доступна в PATH данного сеанса.
